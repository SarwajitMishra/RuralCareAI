## Project Overview

This project implements an AI-assisted rural healthcare triage system designed to support healthcare workers during patient consultations. The application combines structured symptom collection, multimodal AI (text, image, and speech), disease prediction, risk assessment, and explainable recommendations to improve early clinical decision-making in resource-constrained environments.

## Technology Stack

- Python 3.11
- Streamlit
- SQLAlchemy 2.x
- SQLite
- Scikit-learn
- Whisper
- PyTorch
- Transformers
- SHAP

## Modules

- Patient Management
- Consultation Management
- AI Disease Prediction
- Risk Assessment
- Image Analysis
- Voice Analysis
- Disease Knowledge Base
- Reports
- Administration

```bash

```

